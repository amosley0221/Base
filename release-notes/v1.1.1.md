## BASE v1.1.1 — status bar + right-edge gap (standalone fixes)

- **Status bar matches the theme in every orientation.** Capacitor targeted Android 16, which force-enables edge-to-edge and ignores the status-bar color. Set the target back to Android 14 and color the bar natively (dark to match), so portrait *and* unfolded/landscape match — no more grey.
- **No more horizontal scroll / right-edge gap when unfolded.** Clipped at the real page root (the previous attempt clipped the wrong element, which is why it kept scrolling).

Installs over v1.1.0 with no uninstall (same key + app ID). Your data stays — this is an in-place update of the standalone app.
