## BASE v1.3.0 — sync between your phones

**Keep BASE the same on your Android app and your iPhone.** Bills, balances, tasks, notes, school, teams and your name stay in sync. Each phone syncs when you open BASE and a few seconds after you change something.

- **Private and encrypted.** Your data is encrypted on your phone with a passphrase only you know, then stored in a private gist in your own GitHub account. GitHub only sees scrambled data.
- **Smart merging.** Changes merge item by item: a bill added on one phone and a task added on the other both stay. If the same thing was edited on both, the newer edit wins. Deleting something on one phone deletes it on the other.
- **Stays on each phone:** your Claude API key, light/dark theme, weather city and the floating agent's settings.

### Set it up
1. **Android:** Settings → **Sync between devices** → tap **Create a GitHub token**. Leave only the **gist** box checked, choose an expiration, then generate and copy the token. Paste it into BASE, pick a passphrase, and tap **Turn on sync**.
2. **iPhone:** open BASE (refresh once so it updates), go to Settings → **Sync between devices**, paste the **same token and passphrase**, and choose **Use the synced copy here**. That replaces the old sample data on the iPhone with your Android data.

If a token expires, sync shows "Problem" in Settings. Create a new token and turn sync back on with the same passphrase.

Installs over v1.2.5 (same key, in place; your data stays).
