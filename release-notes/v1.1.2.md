## BASE v1.1.2 — fix grey bars + fill the screen

The grey status bar, grey bottom line, and grey "gaps" were all the **window background** showing through the system bars (on this device the bars are transparent and show whatever's behind them). It was defaulting to system grey. Now:

- **Window background is BASE's dark color**, so the status bar, navigation bar, and any edge areas are dark and blend with the app — in both folded and unfolded.
- **Edge-to-edge target restored** so the app fills the whole screen (no letterbox/gap).
