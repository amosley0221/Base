## BASE v1.0.2 — unfolded Home dashboard

### Unfolded / tablet layout
- The wide Home hero no longer just stretches the phone layout. On the **Galaxy Z Fold's unfolded screen** (and tablets), it now shows an **at-a-glance strip** that fills the space with live info:
  - **Classes today** (and your next class time)
  - **Next bill** (amount + when, flagged red if overdue)
  - **Top task** for today
- The strip fades with the hero as you scroll, and is hidden on phones where the single-column layout already fits.

Installs over v1.0.1 with no uninstall. This also reaches the installed app automatically once the website updates — reopen BASE to see it.
