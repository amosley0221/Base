## BASE v1.0.7 — add-team fix + status bar in all orientations

- **Fixed "None found" when adding teams.** The team picker now falls back to the standings feed (the same data that powers live scores) when the teams endpoint comes back empty, and pulls the full list for big college leagues. You can add teams for every league again.
- **Status bar now matches your theme when unfolded too.** The system status/navigation bars are set to BASE's dark background at the Android level, so they match in landscape / unfolded — not just portrait. (This one needs the new APK installed, since it's a native change.)

Installs over v1.0.6 with no uninstall. The team fix also reaches the installed app from the website on reopen; the status-bar change requires installing this APK.
