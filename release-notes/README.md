# Release notes

Write a file named after the tag you're about to push, e.g. `v1.0.0.md`.
Its contents become the body of the GitHub Release for that version.
If the file is missing, the annotated tag message is used instead, and
GitHub's auto-generated commit list is always appended either way.

Example — `release-notes/v1.0.0.md`:

    ## What's new
    - First public build of BASE for Android
    - Budget, School/GPA, Scoreboard, Notes, Calendar
