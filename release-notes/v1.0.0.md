## BASE for Android — first release

The full BASE homebase, installable as an Android app:

- **Home** — upcoming bills, next payment, GPA and upcoming assignments at a glance
- **Budget** — cards, income, bills & subscriptions with due dates and before/after-tax totals
- **School** — GPA calculator, semesters → courses → assignments, AI essay drafting
- **Scoreboard** — live scores for the leagues you follow, box scores, and the wire
- **Notes, Calendar, Plan** — everything else in your homebase

Installs over any previous build without uninstalling. Content updates
automatically whenever the website updates — no new APK needed for those.
