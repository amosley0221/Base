## BASE v1.1.0 — now a standalone app (Capacitor)

BASE is now a **fully standalone Android app**. The web app is **bundled inside the APK** instead of loaded from the website, which means:

- **Works offline** — everything is in the app.
- **Native control** — the status bar now matches BASE's theme in **every orientation** (portrait *and* unfolded/landscape), handled natively. No more grey bar, no fullscreen workaround.
- Future updates ship as a new APK from this Releases page (installs over the top, no uninstall — same signing key and app ID).

### ⚠️ One-time step: bring your data across
Because the app now runs from its own internal storage (not the website's), your existing data **won't carry over automatically**. To move it:

1. **Before updating** — open your current BASE, go to **Settings → Back up / Export**, and save the backup file.
2. Install this **v1.1.0** APK.
3. Open it, go to **Settings → Restore / Import**, and load that backup file.

(If you skip this, v1.1.0 starts fresh with the sample data — your old data isn't lost, it's just in the previous version.)
